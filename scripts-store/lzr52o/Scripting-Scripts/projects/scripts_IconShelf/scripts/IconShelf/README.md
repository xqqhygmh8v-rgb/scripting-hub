# IconShelf

把喜欢的图标集，收进同一个地方。

**作者：CookiePie** · 运行环境：Scripting

IconShelf 是一个运行于 Scripting 的图标集订阅管理工具，用来统一收藏和管理代理 App、Emby 播放器等场景中使用的图标集。

不用再翻聊天记录寻找订阅链接，也不必在更换软件时重新整理收藏。将图标集订阅添加到 IconShelf，即可完成分组整理、图标预览、搜索和更新，让收藏更有条理，使用更方便。

## 主要功能

- **订阅管理**：支持兼容格式的 JSON 图标集订阅，自动读取图标包名称，也可自定义命名。
- **自由分组与排序**：支持分组重命名、删除和拖动排序，图标集可调整全局顺序。“未分类”固定在最后。
- **预览与全局搜索**：连续滚动浏览，支持单套搜索和跨图标集按名称搜索，结果标明来源。
- **复制图标链接**：长按图标，在菜单中选择“复制图标链接”。
- **订阅更新**：支持单独更新和全部更新，获取失败保留上次成功的清单。
- **快捷导入**：已接入 Loon、Quantumult X 图标集添加链接，最终添加结果以目标 App 为准。QX 已有用户实机成功反馈。
- **备份恢复**：自选文件位置导出、恢复名称、分组、排列顺序和订阅链接。

## 安装与运行

本目录提供完整源码，不是独立 iOS App。需要安装 Scripting。

将本目录中的全部 `.ts`、`.tsx` 文件及 `script.json` 放入 Scripting 的同一个 `IconShelf` 项目中，运行 `index.tsx`。不要只复制入口文件，也不要覆盖其他项目。

首次使用点击右上角“＋”添加图标集 JSON 链接。名称留空时优先采用 JSON 顶层 `name`，其次采用 URL 文件名。

支持的基本格式：

```json
{
  "name": "示例图标集",
  "description": "可选说明",
  "icons": [
    { "name": "示例图标", "url": "https://example.com/icon.png" }
  ]
}
```

## 数据与注意事项

- 本仓库不包含作者的个人订阅库、Storage 数据或备份文件；新用户从空订阅库开始。
- 图片按需联网加载；搜索使用已获取的本地图标清单。
- 备份不包含图片缓存与图标清单，恢复后需“全部更新”。恢复备份会替换当前订阅库，操作前有确认。
- 私密订阅地址可能包含令牌，请勿公开上传个人备份。
- 工具不主动设置 Pro 校验，但 Scripting 免费版的完整兼容性尚未实测，不承诺无需 Pro。
- **覆盖升级的完整流程尚未验证**。暂未配置自动更新；不要删除旧脚本后重装来升级。现有用户试用新版前请导出备份，确认更新保留原项目的数据身份。这是当前测试阶段的说明，不代表已完成无损升级保障。
- 图标及图标集内容属于各自作者；本工具不附带或重新分发这些图标。

IconShelf，让图标集有处收藏，也随时可用。
