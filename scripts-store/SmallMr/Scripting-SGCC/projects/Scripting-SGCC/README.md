# SGCC Usage 网上国网用电

网上国网小组件：大号日历、中号模块化摘要、三种小号内容，以及浮岛 / 格栅两套可切换主题。

## 使用

直接导入仓库根目录的 `Scripting-SGCC-1.5.9.scripting`，或在 Scripting 中新建脚本后放入本仓库文件。

脚本在 Scripting 中显示为 **网上国网用电**。更新旧安装时请确认选择的是新名称，避免继续预览到参考项目。

1. 打开脚本设置，填写网上国网**手机号**和**密码**（密码只存在本机钥匙串）。
2. 首次登录（新设备）国网会要求短信验证：点「发送短信验证码」，把收到的 6 位验证码填入「短信验证码」，再点「立即刷新」或预览小组件。
3. 刷新成功后，在「户号」里选择要显示的户号。
4. 到桌面添加小组件，支持小号、中号、大号，以及锁屏的矩形、圆形、行内样式。

## 两套主题

在设置 → 外观里切换，大、中、小号会一起切换：

- **浮岛**：纯白画布 + 浅绿色模块，不用外层画布框。
- **格栅**：纯白画布 + 中性灰模块，更平、更像一块数据面板。

两套主题内部都保持四边等距；不使用大面积深色块、日历热量底色和长进度条。

## 各尺寸内容

- **大号**：本月 / 昨日摘要、本月每日用电日历（日期在上、度数在下，最高红、最低蓝、最后一个有数据的日子用琥珀，只用文字颜色区分；每周可从周一或周日开始；按当月实际周数自动拉伸，5 行月份行更高、6 行月份自动压紧，底部间距恒定）、上月 / 本年模块、阶梯状态。
- **中号**：本月 / 昨日摘要、上月 / 本年模块（含金额）、阶梯状态。
- **小号**：三种可配置内容——
  - **本月**：本月 + 昨日 + 阶梯
  - **账单**：上月 + 本年（含金额）+ 阶梯
  - **阶梯**：阶梯主模块 + 本月

小号模式在设置 → 小号组件里选择。想在同一屏放多个小号并显示不同内容时，可在每个小组件的参数里单独覆盖（见下方“组件参数”）。

## 户号与组件参数

设置里的「户号」是默认户号，刷新后会自动列出当前账号下的户号。

也可以长按小组件 → 编辑小组件 → 参数，临时覆盖：

- `0` / `1`：第一户、第二户（从 0 开始）
- `month` / `bill` / `tier`：小号内容
- `island` / `grid`：浮岛 / 格栅主题（可让两个组件同时显示两套主题）
- `0;bill;grid`：同时指定户号、小号内容和主题

没有参数时使用设置里的默认值。最多读取 6 个户号。

## 阶梯

- 第一阶梯上限默认 2760 度，第二阶梯上限默认 4800 度，按年累计电量计算。
- 第一、第二阶梯显示「本阶梯剩余 X 度」；第三阶梯显示「本年 X 度」。
- 组件里用绿、琥珀、棕三段短线表示三档阶梯，不写“第一阶梯”等汉字。

## 设置项

- **网上国网账号**：手机号、密码、短信验证码
- **户号**：选择默认户号
- **数据**：立即刷新、清除数据缓存
- **外观**：浮岛 / 格栅
- **大号组件**：每周从周一或周日开始；日历度数保留一位 / 两位小数
- **数字格式**：千分位逗号显示 / 隐藏；本月小数不显示 / 保留一位
- **阶梯**：第一阶梯上限、第二阶梯上限
- **小号组件**：本月 / 账单 / 阶梯
- **数据更新**：4 / 6 / 8 / 12 / 24 小时

## 数据与刷新

- 直连网上国网 App 接口，缓存时长由设置里的「数据更新」决定（默认 4 小时）；请求失败时回退到缓存。
- 「清除数据缓存」后下次刷新会重新请求。
